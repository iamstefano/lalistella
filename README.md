# La Listella 🍩

A personal to-do and shopping list built with vanilla JavaScript, Sass, and Vite.

## Features

- Add, complete, filter, and remove items.
- Clear all completed items at once.
- Tasks and the selected color theme are saved in this browser on this device using `localStorage`.
- No account or remote database is required. The list is private to the browser profile and is not synced to other devices.
- Responsive layout, keyboard-friendly controls, and five color themes.

## Development

Install dependencies with `npm install`, then start the local Vite server with `npm run dev`. Run `npm run build` to create a production build.
